Privacy and security

The public repository exposes the encrypted file, format and KDF parameters, file sizes, commit times and GitHub commit attribution. Anyone can copy the file and try passwords offline. PBKDF2 slows each guess. A unique, randomly generated passphrase is essential.

Git history retains old ciphertext under the old passphrase. Changing it protects the newly encrypted file. Anyone with an old copy and its old passphrase can still decrypt it. Public snapshots may also be copied or restored by someone with repository write access.

A stolen token can modify repository contents, including the app itself. Someone who controls the HTML served to your browser can replace this page and capture passphrases, tokens and unlocked data. The hash-based Content Security Policy reduces script injection risk. It cannot protect against a compromised publisher, browser, extension or device. GitHub Pages project sites on the same hostname share a browser origin, so use a dedicated origin where possible.

Bank and savings balances are entered manually. The optional Twelve Data connection refreshes quotes while this tab is open, with daily market closes used for historical valuation. Price delay and symbol coverage depend on your provider plan. Merge uses per-record timestamps. In a simultaneous edit to one record, one version wins. Device clock differences affect ordering. Use one editing tab per device because tabs share one local cache. Deletions are retained as encrypted tombstones to prevent an older device from restoring deleted records.
